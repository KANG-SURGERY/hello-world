# 매일 아침 기상 브리핑 자동 발송

매일 아침 07:00(KST) 성남 분당·서울 기준 기상 브리핑을 `kangborina@gmail.com`으로 받기 위한 설정 기록.

## 구성

Claude Routine(예약 트리거)이 매일 아침 새 Claude 세션을 실행한다. 세션이 기상 정보를
수집·정리하고, 실행 완료 알림이 계정 이메일과 휴대폰 푸시로 전달된다.

| 항목 | 값 |
| --- | --- |
| Trigger ID | `trig_01UawxihT7xnfquPfdPhpAKY` |
| 이름 | 매일 아침 기상 브리핑 (분당·서울) |
| Cron (UTC) | `0 22 * * *` |
| 실행 시각 (KST) | 매일 07:00 |
| 실행 방식 | 매 실행마다 새 세션 생성 (`create_new_session_on_fire`) |
| 알림 채널 | 이메일 + 푸시 |
| 수신 주소 | 계정 이메일 (`kangborina@gmail.com`) |

Cron은 UTC로 해석되므로 KST 07:00은 전날 22:00 UTC에 해당한다. 시각을 바꾸려면
원하는 KST 시각에서 9시간을 뺀 값을 `cron_expression`에 넣는다.

## 브리핑 항목

1. 오늘 예보 — 분당·서울의 최저/최고기온, 체감온도, 하늘상태, 강수확률·강수량, 바람, 습도
2. 주간 전망 — 오늘 포함 7일 일별 최저/최고기온과 강수, 이번 주 기온 흐름의 변곡점
3. 기상특보·예비특보 — 호우·폭염·한파·강풍·대설·건조·태풍·황사 (수도권 해당 여부 표시)
4. 태풍 — 발생 태풍의 위치·강도·진로, 한반도 영향 가능성과 시점
5. 기타 — 지진, 산사태·홍수 경보, 미세먼지 예보 등급, 자외선·오존

주요 출처: 기상청 날씨누리(weather.go.kr), 국가태풍센터(typ.kma.go.kr),
에어코리아(airkorea.or.kr), 국민재난안전포털.

## 운영

- 목록 확인 / 수정 / 삭제: Claude에게 "기상 브리핑 Routine 확인(또는 시각 변경, 중단)"이라고
  요청하면 `list_triggers` / `update_trigger` / `delete_trigger`로 처리한다.
- 즉시 한 번 받아보려면 "기상 브리핑 지금 한 번 보내줘"라고 요청한다 (`fire_trigger`).
- 발송 시각·지역·항목은 Routine 프롬프트를 수정해 언제든 바꿀 수 있다.

## 제약

- 이 환경의 Gmail 커넥터는 **초안 생성만 가능하고 발송 기능이 없다.** 따라서 메일 발송은
  Gmail이 아니라 Routine 완료 알림 이메일로 이뤄지며, 발신자는 Claude, 수신자는 계정
  이메일로 고정된다. 다른 주소로 보내려면 Gmail에서 전달 규칙을 걸어야 한다.
- Routine이 실행하는 세션에는 MCP 커넥터가 붙지 않는다. 브리핑 프롬프트의 Gmail 초안
  저장 단계는 커넥터가 없으면 자동으로 건너뛴다.
