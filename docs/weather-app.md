# 실시간 기상 대시보드 (`docs/index.html`)

성남 분당·서울(및 현재 위치)의 날씨를 실시간으로 보여주는 단일 HTML 파일 앱.
빌드 도구, 서버, API 키가 모두 필요 없다. 파일 하나를 브라우저로 열면 동작한다.

## 여는 방법

1. **파일 그대로 열기** — `docs/index.html`을 브라우저로 연다. 바로 동작한다.
2. **GitHub Pages** — 이 브랜치를 `main`에 머지한 뒤 저장소
   Settings → Pages에서 Source를 `main` 브랜치 `/docs` 폴더로 지정하면
   `https://kang-surgery.github.io/hello-world/` 로 접속된다. 휴대폰 홈 화면에
   추가해 두면 앱처럼 쓸 수 있다.

## 화면 구성

| 섹션 | 내용 |
| --- | --- |
| 위험 신호 | 폭염·한파·호우·대설·강풍·열대야·도로결빙·자외선·미세먼지 판정, 심각도 순 정렬 |
| 현재 실황 | 기온, 체감온도, 날씨, 습도, 바람, 강수, 오늘 강수확률 |
| 24시간 예보 | 기온 곡선 + 강수확률 막대 (x축 공유, 십자선 툴팁) |
| 주간 전망 | 7일 최저~최고 기온 구간 막대, 강수확률·강수량 |
| 대기질·자외선 | PM10, PM2.5, 자외선 지수 + 에어코리아 등급 |
| 공식 정보 | 기상청 특보·태풍·지진, 에어코리아, 국민재난안전포털 링크 |

## 동작

- **데이터**: [Open-Meteo](https://open-meteo.com) 예보 API와 대기질 API. 무료,
  API 키 불필요, CORS 허용이라 브라우저에서 직접 호출한다. 시각은 모두
  `Asia/Seoul` 기준 문자열로 받아 그대로 표시하므로 기기 시간대와 무관하다.
- **갱신**: 10분마다 자동 갱신. 화면으로 돌아오거나 온라인 상태가 복구될 때도
  다시 불러온다. 우측 상단 버튼으로 수동 갱신.
- **오프라인**: 마지막 성공 데이터를 `localStorage`에 지역별로 저장해 두고,
  갱신 실패 시 흐리게 표시하면서 마지막 갱신 시각을 안내한다.
- **접근성**: 두 차트 모두 `표로 보기` 토글로 같은 값을 표로 볼 수 있다.
  위험 신호는 색만이 아니라 아이콘 + 문구로 구분한다. 다크 모드는 별도 색상값으로
  지정돼 있다.

## 위험 신호 판정 기준

기상청 특보 기준 중 이 API가 제공하는 필드로 계산 가능한 항목만 옮긴 **자체 판정**이며,
공식 특보가 아니다. 앱 화면에도 같은 문구를 표시한다.

| 항목 | 주의 수준 | 경보 수준 |
| --- | --- | --- |
| 폭염 | 최고 체감 33℃ | 최고 체감 35℃ |
| 한파 | 최저 −12℃ | 최저 −15℃ |
| 호우 | 일 강수 80mm | 일 강수 150mm 또는 시간당 30mm |
| 대설 | 적설 5cm | 적설 20cm |
| 강풍 | 최대 풍속 14m/s | 최대 풍속 21m/s |
| 자외선 | 지수 8 | 지수 11 |
| 미세먼지 | PM10 81 또는 PM2.5 36 | PM10 151 또는 PM2.5 76 |

이 밖에 열대야(최저 25℃ 이상), 도로 살얼음(영하 + 강수), 내일 기온 급변(±7℃)을
별도 안내한다.

## 다루지 않는 것

**태풍 진로, 공식 특보 발효 현황, 지진 정보는 이 앱이 직접 가져오지 않는다.**
해당 데이터는 기상청 API 키가 필요하고 브라우저 직접 호출(CORS)이 막혀 있어,
공식 페이지 바로가기로 대신했다. 매일 아침 메일 브리핑은 이 항목들까지
포함한다 — [`daily-weather-briefing.md`](daily-weather-briefing.md) 참고.

## 수정 지점

`docs/index.html` 한 파일 안에 모두 들어 있다.

- 지역 추가/변경 → 스크립트 상단 `LOCATIONS`
- 갱신 주기 → `REFRESH_MS`
- 위험 판정 기준 → `risks()`
- 대기질 등급 구간 → `PM10_GRADE` / `PM25_GRADE` / `UV_GRADE`
- 색상 → `:root` 및 `prefers-color-scheme: dark` 블록의 CSS 변수
