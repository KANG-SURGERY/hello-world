# 60초 홍보영상 (환자 대상)

`index.html` 파일 하나로 동작하는 60초 자동 재생 영상입니다. 외부 파일·인터넷 연결이
필요 없으므로 브라우저로 열기만 하면 바로 재생됩니다.

## 재생 방법

`index.html`을 더블클릭하거나 브라우저에 끌어다 놓으세요.

| 조작 | 방법 |
|---|---|
| 재생 / 일시정지 | `▶ 재생` 버튼 또는 스페이스바 |
| 처음부터 | `↻ 처음부터` 버튼 또는 `R` 키 |
| 음악 끄기 | `🔊 음악 켜짐` 버튼 |
| 영상 파일로 저장 | `⬇ 영상 파일로 저장` 버튼 |
| 녹화 모드 | `🎬 녹화 모드` 버튼 (UI를 숨기고 전체화면으로 전환 후 자동 재생) |

## 배경음악

잔잔한 피아노곡이 들어 있습니다. **음원 파일이 아니라 브라우저가 그 자리에서
합성하는 소리**라 별도 파일이 필요 없고, 저작권 문제도 없습니다.

화성이 장면을 따라갑니다 — 가단조(진단)에서 바장조로 열리고(전환), 다장조로
따뜻해졌다가(소개), 사-가-바-다 진행으로 고조된 뒤(근거·데이터), 다장조로
풀리며 58초부터 페이드아웃됩니다. 곡을 바꾸려면 `index.html`의 `scheduleScore()`
함수에서 음표를 수정하면 됩니다.

## 영상 파일로 만들기

### 방법 1 — `⬇ 영상 파일로 저장` (권장, Chrome)

음악까지 한 파일에 담깁니다.

1. `⬇ 영상 파일로 저장` 버튼을 누릅니다.
2. 공유할 화면을 고르는 창에서 **이 탭**을 선택하고, 왼쪽 아래
   **「탭 오디오도 공유」를 반드시 켭니다.** (이걸 켜지 않으면 음악이 빠집니다.)
3. 60초 뒤 `promo-60s.webm` 파일이 자동으로 저장됩니다.
4. mp4가 필요하면 변환합니다: `ffmpeg -i promo-60s.webm -c:v libx264 -c:a aac promo-60s.mp4`

### 방법 2 — 화면 녹화 기능

⚠️ macOS의 `⌘ + ⇧ + 5`와 Windows Game Bar는 **시스템 소리를 담지 못해 음악이
빠진 영상**이 됩니다. 소리가 필요 없거나 편집 단계에서 다른 음악을 얹을 때만
쓰세요. `🎬 녹화 모드` 버튼을 먼저 눌러 UI를 숨기고 녹화하면 됩니다.

나레이션을 넣을 경우 각 장면의 자막을 그대로 읽으면 분량이 맞습니다.

## 구성 (총 60초)

| 시간 | 장면 | 내용 |

| 0–7초 | 도입 | "직장암입니다" — 환자가 느끼는 순간 |
| 7–14초 | 전환 | 중요한 것은 그 다음 |
| 14–24초 | 인물 | 이름 · 소속 · 진료 분야 |
| 24–36초 | 근거 | COREAN 임상연구 |
| 36–48초 | 데이터 | 핵심 수치 3개 |
| 48–55.5초 | 철학 | 치료 이후의 삶 |
| 55.5–60초 | 마무리 | 진료 안내 |

### 3. 의료광고 심의

환자를 대상으로 하는 의료광고는 의료법에 따라 사전 심의 대상이 될 수 있습니다.
병원 홍보팀 또는 대한의사협회 의료광고심의위원회에 확인 후 사용하세요. 특히
치료 성적·생존율 수치를 포함한 표현은 심의에서 자주 문제가 되는 부분입니다.
