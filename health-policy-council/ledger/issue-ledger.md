# 누적 쟁점 대장

이 파일이 이 시스템의 **기억**입니다. 매 회차 프롬프트에 통째로 들어가고,
회의 규칙 §7이 "여기 이미 있는 쟁점은 반복하지 말라"고 강제합니다.
**갱신하지 않으면 루프가 매주 같은 회의를 반복합니다.**

## 갱신 방법

회차가 끝나면 `sessions/<날짜>-<의제>/brief.md`의 「수정: 쟁점 대장 갱신 지시」 절에
붙여넣을 수 있는 표 행이 나옵니다. 그대로 아래 표에 반영하세요.
Claude Code를 쓴다면 "이번 회차 결과를 쟁점 대장에 반영해 줘"로 충분합니다.

## 상태 값

| 상태 | 뜻 |
|---|---|
| `열림` | 계속 다툼 중 |
| `조건부 수렴` | 특정 조건 아래서는 합의됨. 조건이 열이 아니라 쟁점 서술에 들어감 |
| `검증 대기` | 데이터만 확인되면 판정 가능. 「검증 필요 목록」과 연결 |
| `해소` | 판정됨 또는 무의미해짐. 다시 꺼내지 말 것 |

## 판정 가능성 값

`데이터로 판정 가능` / `가치 판단이라 판정 불가` / `아직 데이터 없음`

## 해소된 쟁점 보관소

한 번 판정된 쟁점은 위 표에서 여기로 옮깁니다. 삭제하지 마십시오 —
"이건 이미 결론 났다"는 기록 자체가 다음 회차의 시간을 아낍니다.

| # | 쟁점 | 어떻게 판정됐는가 | 회차 |
|---|---|---|---|
