## 코드 진행 (C major)

```
[Verse]      C  -  G/B  -  Am  -  Em/G  |  F  -  C/E  -  Dm7  -  G
[Pre]        F  -  G  -  Em  -  Am  |  F  -  G  -  C
[Chorus]     C  -  G  -  Am  -  F  |  C  -  G  -  F  -  G
             (마지막 줄만)  F  -  Fm  -  C          ← Fm에서 마음이 한 번 내려앉음
[Bridge]     Am  -  Em  -  F  -  C  |  F  -  G  -  C  -  C7
             (전조하려면 여기서 D major로 반음 반 올려 Last Chorus)
[Outro]      F  -  C/E  -  Dm7  -  G  -  C
```

- 브릿지 마지막 `C7`은 Last Chorus로 가는 문입니다. 힘을 주고 싶으면 여기서 한 키 올리세요.
- 후렴 끝의 `F → Fm → C`(부점 마이너)가 이 노래의 핵심 정서입니다. 꼭 살려주세요.

## 부를 때

- 1절은 말하듯이, 거의 속삭이듯 부르세요. 잘 부르려 하지 않는 편이 낫습니다.
- 브릿지의 "다시 태어나도"에서 처음으로 목소리를 여세요. 그 전까지는 참는 게 좋습니다.
- 아웃트로 두 줄은 노래하지 말고 그냥 말해주세요. 반주만 남기면 됩니다.
- 기타 반주가 어려우면, 피아노 아르페지오만으로도 충분합니다.

## 손보고 싶을 때

아래 부분은 실제 사연에 맞춰 바꾸면 훨씬 좋아집니다.

- `스물 몇 해 전` → 실제 결혼 햇수 (예: `스물다섯 해 전`)
- `불 꺼진 복도를 지나 돌아오던 밤` → 두 분만 아는 장면으로 교체
- `이 골목에서` → 처음 만난 장소
- `여보` → 평소 부르는 호칭
