# 진료 평판 모니터링 (Reputation Monitoring)

강성범 교수(분당서울대학교병원 외과, 대장암·직장암)에 대한 **일반인·환자의 온라인 언급과 평가**를
주 1회 자동 수집·요약하여 `kangborina@gmail.com`으로 전달하기 위한 운영 정의입니다.

블로그·카페에 직접 참여하지 않고도 환자 피드백을 간접적으로 확인하는 것이 목적입니다.

## 구성

| 파일 | 내용 |
|---|---|
| `search-plan.md` | 주간 검색 쿼리 세트, 동명이인 필터, 소스 목록, 수집 한계 |
| `routine-prompt.md` | 자동 실행(Routine)에 등록된 프롬프트 원문 (버전 관리용) |
| `reports/` | 주간 리포트 보관 |

## 운영 방식

- **주기:** 매주 토요일 오전 07:50 (KST) — cron `50 22 * * 5` (UTC 기준)
- **Routine ID:** `trig_015J4MSn3Ua8Tmjjy71HsnKW`
- **실행:** 매회 새 세션이 생성되어 `routine-prompt.md`의 지시를 수행
- **전달:** 실행 완료 알림 메일이 `kangborina@gmail.com`으로 발송됩니다.
  세션의 **마지막 응답이 곧 메일 본문**이므로, 프롬프트가 마지막 응답을
  "메일로 읽히는 리포트" 형식(40줄 이내)으로 쓰도록 지시합니다.

> **제약 (실측):**
> - 자동 실행 세션에는 **커넥터(Gmail 등) 도구가 제공되지 않습니다.**
>   (조직 정책상 Routine에 커넥터를 첨부할 수 없음 → 세션이 메일을 직접 보낼 수 없음)
> - Gmail 연동 도구 자체에도 **발송 기능이 없고 초안 생성만** 가능합니다.
> - 따라서 전달 경로는 **완료 알림 메일 1개**로 단일화했습니다.

## 리포트 구성

1. 핵심 요약 (5줄 이내 — 이것만 읽어도 파악 가능하게)
2. 본인 관련 언급 — 긍정 / 개선 참고 / 사실 오류
3. 학술·연구·언론 노출
4. 대장암 진료 분야 전반의 평판 동향
5. 참고할 만한 액션 제안
6. 수집 한계 명시

## 변경 방법

| 원하는 변경 | 방법 |
|---|---|
| 발송 요일·시간 | `update_trigger`로 `cron_expression` 수정 (UTC 기준) |
| 검색 범위·리포트 형식 | `routine-prompt.md` 수정 후 `update_trigger`로 `prompt` 동기화 |
| 일시 중단 | `update_trigger`로 `enabled: false` |
| 완전 삭제 | `delete_trigger` |

## 주의사항

- 수집 대상은 **공개된 웹 문서**에 한정합니다. 로그인이 필요한 카페 본문은 수집하지 않습니다.
- 환자 개인을 특정할 수 있는 정보(작성자 ID, 나이, 병력 등)는 리포트에 옮기지 않고,
  **평가의 취지만** 요약합니다.
- 부정적 후기에 대해 온라인에서 대응·반박하지 않습니다. 수집은 참고 목적입니다.
